📦 LMS Material — Upload & Download Flow Tester

Test the full pre-signed S3 upload/download flow. Works against a locally running Spring Boot app (dev profile).

1 Authenticate (get JWT)

JWT Token (auto-used in all requests below)
— not authenticated —

2 Create Material (get upload URL)

POST /api/{courseId}/material
Returns a pre-signed upload URL + material record in PENDING status.

3 Upload File (PUT to pre-signed URL)

Put the file directly to S3/LocalStack via the pre-signed URL returned in step 2. The backend is NOT involved — this is a direct S3 PUT request.

⚠️ CORS must be enabled on the bucket. The init-s3.sh script handles this for LocalStack.

4 Confirm Upload

PATCH /api/{courseId}/material/{materialId}/confirm-upload
Backend verifies the file exists in S3 (HeadObject) and sets status to UPLOADED.

5 Download Material (get download URL)

GET /api/{courseId}/material/{materialId}
Returns the material info with a pre-signed download URL. Only provided if the material is marked as downloadable.
